# Crunchmates

Crunchmates is a React + TypeScript ecommerce demo for a chips brand. It includes a storefront, product detail pages, cart and checkout flows, customer login, and a separate admin workspace for catalog and content management.

## Run locally

```bash
npm install
npm run dev
```

## What is included

- Animated brand landing page inspired by premium snack packaging
- Product browse, detail, cart, and checkout flow
- Customer account area with order history
- Separate admin login and protected admin pages
- Admin tools for products, homepage copy, feature blocks, and order status

## Notes

- The app stores data in localStorage, so admin edits persist across refreshes.
- Product art can be uploaded from the admin product form, or left to use built-in visuals.
